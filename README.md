# StudyLoop v2.0

GitHub Pages でそのまま動作する、軽量・オフライン対応の暗記カード＆テスト学習アプリです。

## 主な変更点（v1.3 → v2.0）
- **バグ修正**
  - サンプル数式・見本CSVの LaTeX バックスラッシュ未エスケープを修正
  - 4択・スワイプ・ボタン判定のタイマー競合（レースコンディション）を解消
  - 出題設定変更時と途中再開セッションの衝突を解消
  - 5問復習タイム中のフェーズ表示バッジ（`復習中`）を有効化
  - ホーム画面から通常CSVを読み込んだ際に新規単語帳を自動作成するよう修正
  - カード編集モーダルで画像の確認・変更・削除、および背景クリック・Escキー対応
  - 赤文字入力のロック位置を通常出題（Q→A）と反転出題（A→Q）で分離
- **脱・AIらしさ（引き算のUI）**
  - 絵文字を廃止し、単色SVGアイコンへ統一
  - 自明な説明文を削除し、詳細設定やCSVガイドを折りたたみ化
  - カードめくり速度を最適化（0.24s）し、スワイプ表示を整理
  - `alert` / `confirm` / `prompt` を独自モーダル＆トースト通知に置換
- **テスト機能**
  - 学習タブ上部で「暗記 / テスト」を切り替え可能
  - 問題数（10 / 20 / 30 / 全問・ランダム抽出）と採点方式（1問ごと / 終了後にまとめて判定）を選択
  - テスト結果画面から「×のみ表示」「×だけ再テスト」「×に一括で★ピン留め」に対応
- **アーキテクチャ刷新・PWA化**
  - ES Modules（`js/`）および機能別CSS（`css/`）へ分割（ビルド不要）
  - 添付画像を IndexedDB へ分離保存し、JSON完全バックアップ／復元（追加・上書き選択）に対応
  - `manifest.webmanifest` と `sw.js` によるPWAインストール・オフライン動作（KaTeXキャッシュ含む）

## GitHub Pages での公開方法
1. ZIPを展開し、中のファイル一式をリポジトリのルートにアップロードします。
2. GitHub リポジトリの **Settings → Pages** から公開ブランチを選択します。
3. 公開URLへアクセスすると、スマホの「ホーム画面に追加」からPWAとして利用できます。

> 注意：ES Modules と Service Worker を使用しているため、ローカルで直接 `index.html` をダブルクリック（`file://`）するとブラウザのセキュリティ制限で動作しません。GitHub Pages または `python -m http.server` などのローカルサーバー経由で開いてください。
