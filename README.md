# StudyLoop v2.1

GitHub Pages で動作する、軽量・オフライン対応の暗記カード＆テスト学習アプリです。

## v2.1 の新機能
- **GAS 連携の短縮URL共有（全員ノー登録）**
  - 1冊共有（デッキ詳細ヘッダー）、複数選択・フォルダ単位・全選択共有（ホームヘッダー）に対応
  - 公開範囲は「URL限定」「検索に公開」を選択可能
  - 正誤履歴・ピン留め・端末内画像参照は自動除外してクリーンに共有
  - 同じURLでの上書き更新および共有削除に対応（「自分の共有」タブ）
  - 受け取る側はURLを開くだけで取り込む単語帳を選択可能
- **公開単語帳・問題のサイト内検索**
  - ホームヘッダーの検索アイコンから、公開された単語帳をタイトル・単元・作成者・問題文で横断検索
- **GitHub Gist 無料クラウド同期（スマホ⇔PC）**
  - 非公開Gistに自動保存・自動同期（2台目は同じトークンを入れるだけで既存Gistを自動検出）
  - 端末とクラウドの双方が変更されていた場合は上書き前に競合確認ダイアログを表示
- **テスト問題数の自由入力**
  - 単元フィルター＋プリセット（10 / 20 / 50 / 全問）に加えて、任意の出題数を直接入力可能

## GitHub Pages への反映手順
1. `StudyLoop-v2.1.zip` を解凍し、`StudyLoop-v2.1` の中身一式をリポジトリのルートに配置します。
2. GitHub Pages の反映後、ブラウザを再読み込みしてください。
