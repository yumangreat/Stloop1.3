# StudyLoop v2.3

GitHub Pages で動作する、軽量・オフライン対応の暗記カード＆テスト学習アプリです。

## v2.3 の新機能・改善
- **進行モードを2×2の4枠に一本化**
  - 上部の「暗記 / テスト」切替を廃止し、「5問ごとに振り返り」「単語カード」「忘却曲線」「テスト」の4枠に整理（説明文を削除してスッキリ表示）
- **「お気に入り」「間違えた問題」を独立トグル化（全モード対応）**
  - 形式の下のオプション欄に「お気に入り」「間違えた問題」スイッチを追加。単独または両方ON（OR条件）で、どの進行モード・テストでも出題を絞り込み可能
- **正誤カウントのリアルタイム＆結果出力**
  - 学習・テスト中の上部バーに `◯ / ×` の数をリアルタイム表示（まとめ判定テスト中は非表示）
  - 学習完了画面・テスト結果画面の双方に「正解 ○問 / 間違い ○問」を明示出力
- **Google アカウント同期（Firebase）＆ GAS 短縮URL共有・公開検索**
  - v2.2 までの Google ワンタップ同期、短縮URL共有、公開検索を引き続き利用可能
